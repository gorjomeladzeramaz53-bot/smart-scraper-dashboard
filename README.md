# FastAPI AI Web Scraper Pro 🚀

A modern, high-performance web scraper powered by FastAPI, Playwright, and AI. It extracts content from websites cleanly and structures it for automated workflows.

## 🛠️ Tech Stack
* Backend: Python, FastAPI, Uvicorn
* Automation/Scraping: Playwright
* Frontend: HTML, Tailwind CSS

## 🚀 How to Run Locally

1. Clone the repository:
git clone https://github.com/https://github.com/gorjomeladzeramaz53-bot/ai-scraper-fastapi.git

2. Create and activate a virtual environment:
python -m venv venv
venv\Scripts\activate

3. Install dependencies:
pip install fastapi uvicorn playwright
playwright install

4. Run the server:
uvicorn main:app --reload
